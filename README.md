# FUT27 Sammelheft

Web-App zum Sammeln und Verwalten der FUT27-Karten. Die Anwendung basiert auf
SvelteKit und bezieht Karten-, Versions- und Batch-Daten aus dem separaten
Repository [`db_fut27cards`](https://github.com/Flo-Kayser/db_fut27cards).

Das Sammelheft bietet die Übersicht und Verwaltung der eigenen Sammlung,
inklusive Kartenansichten, Versionen, Batches sowie Sammelstatus und
Einstellungen.
